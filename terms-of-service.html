2. Description of the App

Nature Compiler is a personal content automation tool that allows connected TikTok accounts to publish nature video compilations using TikTok's official Content Posting API. The App:

  • Sources royalty-free video clips from third-party libraries (e.g. Pexels)
  • Compiles clips into short-form video using FFmpeg
  • Attaches audio from TikTok's native Sounds library at the time of upload
  • Publishes the finished video to TikTok via the official Content Posting API
